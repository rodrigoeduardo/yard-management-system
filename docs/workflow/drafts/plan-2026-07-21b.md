## Findings / conflicts to flag

- **Combobox flicker (item 3): open PR #231** (`fix/material-combobox-popover-flicker`, unmerged) already claims to fix exactly this. `main` does not contain the fix, so the bug reproducing on `main` is expected. Human decision needed: test PR #231's branch — if the flicker is gone there, merge #231 and drop proposal #3; if it still reproduces, promote proposal #3 (builder starts from that branch and root-causes properly).
- **audit_log.user_id (item 2)**: column + trigger already exist (`drizzle/0004_audit_log_user_id.sql`); the trigger populates `user_id` from `auth.uid()`. Root cause: the app talks to Postgres over a direct `postgres-js` connection (`lib/db/index.ts`), so the `request.jwt.claim.sub` GUC that `auth.uid()` reads is never set — `user_id` lands NULL for every app mutation. Fix is app-side session context, not schema.
- **TopLoader (item 1)**: the bar is opt-in per link — `LinkLoaderReporter` must sit inside each `<Link>` (`useLinkStatus` reads its parent Link only). Nav links and action cards have it; `StatCard` (`components/ui/stat-card.tsx`) renders its `<Link>` without one.
