## Notes / decisions

- **#1 scope**: touches `app/(authenticated)/loads/new/page.tsx` and
  `.../removals/new/page.tsx`, plus server actions (`lib/actions/loads.ts`,
  `lib/actions/removals.ts` — currently take `entryDate`+`entryTime` /
  `exitDate`+`exitTime` and call `combineEntryDateTime`). Single
  `datetime-local` yields `YYYY-MM-DDTHH:mm`; either parse directly or split
  before `combineEntryDateTime`. Keep the stored timestamp identical. Could
  split into two issues (loads / removals) if too big — kept as one; change is
  mechanical and shared.
- **#2**: ambiguity resolved with user — "icons match search height only"
  (search fills row, icons stay square sized to input height). Current row:
  `flex flex-wrap items-center gap-3`; `StockSearchInput`/`RemovalSearchInput`
  hardcode `max-w-xs`; icon buttons from `ControlTriggerButton` (`size="icon"`).
- **#3**: `app/login/page.tsx` and `app/register/page.tsx` `main` is
  `flex min-h-screen flex-col items-center justify-center gap-6` with no
  horizontal padding.
