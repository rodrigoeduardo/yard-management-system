## Decisions (human, resolved 2026-07-20)

- **kg→t conversion**: re-label only — no numeric conversion of stored values.
- **Vehicle plate placement**: shown as a removal-log table column ("Placa"), in the last-movement card, removal detail modal, and receipt.
- **Vehicle plate required** in the form for new removals; column nullable for legacy rows.
- **Material rename semantics**: FK model — renaming a material changes how historical loads display. Accepted.
