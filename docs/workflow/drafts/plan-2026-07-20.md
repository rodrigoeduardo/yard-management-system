## Notes for builders (context, not extra scope)

- **Shared shell**: designs share a modal shell (radius 18–20px, deep shadow,
  20–24px padding, plain close icon top-right). Apply via `DialogContent`
  className per modal — do **not** restyle `components/ui/dialog.tsx` globally
  unless every dialog in the app should change (out of scope).
- **Issue 1 keeps instant apply** (human decision): selecting a field or
  direction navigates immediately; the modal stays open so the chips reflect
  the choice. Footer exists for visual parity — `Aplicar` only closes the
  modal, `Limpar` resets order/dir to the section default. Asc/desc chips
  appear only on the selected field's row.
- **Colors/fonts**: map design oklch values to existing tokens where they
  correspond; `Spline Sans Mono` already configured as `--font-mono`.
- **Native date inputs stay** (issue 2): human waived the `De ·`/`Até ·`
  placeholders — keep `type="date"` inputs as-is.
- **Issue 5 mechanism today**: `use-stock-query-nav.ts` / `use-removal-query-nav.ts`
  do `router.push` → full RSC navigation; perceived refresh comes from the
  route-level loading state/scroll reset. Likely fix: wrap navigation in
  `useTransition` and keep stale UI while pending — builder decides.
