# Plan — 2026-07-26

Session input: increase the font size of the information printed on each QR label, **without changing
label dimensions**.

Board state at planning time: **0 open issues**. No duplicates possible.

## Findings

- The printed tag is `components/loads/qr-print-view.tsx` (grid item `<Card>`), driven by
  `@page { size: 100mm 50mm; margin: 0 }` in `app/globals.css` (added in #217).
- The card has **no print-specific font sizes** — the three text lines inherit the screen sizes
  (`text-[13px]`, `text-[11.5px]`, `text-xs`/`text-[12.5px]`), i.e. ≈3.0–3.4mm on paper.
- Geometry budget on a label: 100×50mm minus `print:p-[4mm]` → 92×42mm content; QR is
  `print:w-[42mm]` plus `print:gap-[4mm]` → the text column is **46mm wide × 42mm tall**. That is the
  only hard constraint; there is ample vertical headroom for larger type.
